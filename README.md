# 🚲 서울특별시 공공자전거(따릉이) GIS 비즈니스 인텔리전스(BI) 대시보드

서울시 공공자전거(따릉이) 대여 로그 데이터와 25개 자치구 시군구 행정경계 공간정보(`sig.shp`)를 연계하여, 깊은 비즈니스·정책적 의사결정 인사이트를 도출하는 **엔터프라이즈급 Streamlit 대시보드 웹 애플리케이션**입니다.

---

## 🌟 핵심 특징 & 기술적 성과

1. **GIS 공간정보(CRS) 정밀 보정 및 고속 최적화**:
   - `sig_20230729/sig.shp`의 좌표계가 **EPSG:5179 (GRS80 UTM-K)** 임을 자동 검증·판별하고, WGS84 위경도(`EPSG:4326`)로 완벽 재투영(Reprojection).
   - 서울시 25개 자치구만 추출한 경량 `seoul_districts.geojson` 캐시 파이프라인을 구축하여 지도 렌더링 속도를 0.05초 단위로 단축.
2. **다층 레이어 공간 분석 (Multi-Layer Spatial Intelligence)**:
   - **거시적(Macro)**: 25개 자치구 경계 코로플레스(Choropleth Map) 단계구분도 시각화 (이용량, 회전율, 인프라 밀도, 평균 이동거리 등 선택형).
   - **미시적(Micro)**: 서울 시내 2,789개 대여소의 위경도 기반 산점도(Scatter Map) 및 운영 상태(과밀/적정/유휴) 분류.
   - **핫스팟 오버레이**: 상위 Top 15 슈퍼 핫스팟 대여소 하이라이트.
3. **실무형 비즈니스/정책 인텔리전스 (BI Framework)**:
   - **자전거 회전율(Turnover Rate = 이용건수 / 거치대수)** 기반 불균형 진단.
   - **인터랙티브 거치대 재배치 시뮬레이터**: 공급 부족(Over-Demand) 대여소와 유휴(Under-Demand) 대여소를 분류하고 거치대 이전 전략 제언.
   - **ESG 탄소중립 & 사회경제적 편익 환산기**: 승용차 대체 유류비 절감액 및 시민 건강 증진 가치 산출.
4. **프리미엄 UI/UX & 글래스모피즘 디자인**:
   - 딥 다크/차콜 테마 (`#0d1117`, `#161b22`) 기반 네온 악센트 컬러와 카드 인터랙션.
   - Plotly 7.x 최신 지도 API(`px.choropleth_map`, `px.scatter_map`) 적용.

## 🚀 대시보드 실행 방법

### 방법 1: 배치 파일 더블클릭 (가장 간편)
`run_dashboard.bat` 파일을 더블클릭하여 실행합니다.

### 방법 2: 터미널 명령어로 직접 실행
```bash
python -m streamlit run app.py --server.port=8501
```
웹 브라우저에서 `http://localhost:8501` 에 접속합니다.
